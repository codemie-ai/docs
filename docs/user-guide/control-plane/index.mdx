# Control Plane

The AI/Run Control Plane shows project leads what AI-assisted delivery produced and what it cost.
It combines CodeMie CLI sessions with tracker tickets and Git merge requests, and shows the results
per project, stream and person.

Engineers use the same CodeMie CLI in every deployment option, so a team can switch options without
starting over.
