# Accessibility

CodeMie provides programmatic structure in the web interface so that assistive technologies, such as screen readers, can interpret and navigate content. This page lists accessibility-related behavior of the platform UI.

## Card Lists

Collections of cards are rendered as semantic lists. Assistive technologies announce such a collection as a list and report the number of items, which allows navigating between cards item by item.

The following card collections are exposed as lists:

| Page               | Cards                                              |
| ------------------ | -------------------------------------------------- |
| Marketplace        | Assistant cards, including related assistant cards |
| Project Assistants | Assistant cards                                    |
| Templates          | Assistant template cards                           |

The visual appearance of the cards is not affected.
