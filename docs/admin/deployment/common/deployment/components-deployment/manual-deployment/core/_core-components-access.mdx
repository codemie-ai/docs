## Access CodeMie Application

Once all core components are deployed, access the CodeMie UI:

```
https://codemie.airun.example.com
```

:::warning User Creation Required
You'll be redirected to Keycloak for authentication, but no users exist yet. You must complete the <a href={props.configurationLink ?? '../../../../../../configuration/index.mdx'}>Configuration</a> guide to create users before you can log in to the application.
:::
