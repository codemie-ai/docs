# Platform Deployment

This section covers deploying AI/Run CodeMie application components onto a provisioned infrastructure. All guides support AWS, GCP, and Azure in a unified format using cloud tabs.

:::info Prerequisites
Before proceeding, ensure you have completed [Infrastructure Deployment](../infrastructure-deployment/) and have a running Kubernetes cluster or VM with the `deployment_outputs.env` file from the infrastructure phase.
:::
