# On-VM Application Deployment (BYO Mode)

After the infrastructure is provisioned manually (VM, storage, networking, DNS), this step deploys the AI/Run CodeMie application stack using BYO (Bring Your Own) mode: `./deploy.sh --byo`.

:::info Prerequisites
Complete all infrastructure phases from [On-VM Infrastructure Deployment](../../../infrastructure-deployment/infrastructure-deployment-on-vm) before proceeding.
:::

## Application Provisioning

<Tabs groupId="cloud-provider">
<TabItem value="aws" label="AWS">

**Configure deployment.conf (BYO Mode)**

`BYO_EC2_HOST` determines the application URL. Set it based on your network mode:

| Network Mode | `BYO_EC2_HOST`                                    | Access              |
| ------------ | ------------------------------------------------- | ------------------- |
| Public IP    | `ec2_public_ip` from Terraform outputs            | Direct HTTPS to EIP |
| Private IP   | `ec2_private_ip` from Terraform outputs           | HTTPS via VPN only  |
| Domain + ALB | Any IP (overridden by `BYO_PLATFORM_DOMAIN_NAME`) | HTTPS via ALB       |

Example `deployment.conf` for Public IP mode:

```bash
TF_VAR_region="eu-north-1"
CODEMIE_VERSION="2.26.0"
COMPOSE_PROFILE="enterprise"

BYO_EC2_HOST="*.*.*.*"
BYO_EC2_USER="ubuntu"
BYO_EC2_SSH_KEY="./terraform/platform/codemie-key.pem"
BYO_EC2_SSH_MODE="ssm"
BYO_EC2_INSTANCE_ID="i-xxxxxxxxxxxxxxxxx"
BYO_AWS_S3_BUCKET_NAME="codemie-user-data"
BYO_AWS_KMS_KEY_ID="<kms-key-id>"
BYO_PLATFORM_DOMAIN_NAME=""
```

**Run BYO Deployment**

```bash
cp /path/to/key.json ./key.json
./deploy.sh --byo
```

**Verify**

```bash
curl -k https://<CODEMIE_HOST>/v1/healthcheck
```

Expected response: `{"status":"ok"}`

</TabItem>
<TabItem value="azure" label="Azure">

**Configure deployment.conf (BYO Mode)**

Fill in the values from Terraform outputs (Phase 2 and Phase 3):

```bash
CLOUD_PROVIDER="azure"
CODEMIE_VERSION="2.26.0"
COMPOSE_PROFILE="enterprise"

BYO_VM_HOST="<vm_private_ip>"
BYO_VM_USER="azadmin"
BYO_VM_SSH_KEY="/path/to/codemie-key.pem"
BYO_VM_SSH_MODE="bastion"
BYO_AZURE_BASTION_NAME="<bastion_name>"
BYO_AZURE_RESOURCE_GROUP="<rg_name>"
BYO_AZURE_VM_RESOURCE_ID="<vm_id>"
BYO_AZURE_STORAGE_ACCOUNT_NAME="<sa>"
BYO_AZURE_KEY_VAULT_URL="<kv_url>"
BYO_AZURE_KEY_NAME="codemie-key"
BYO_PLATFORM_DOMAIN_NAME=""

# If DEPLOY_AI_MODELS=false:
# AZURE_OPENAI_ENDPOINT=""
# AZURE_CLIENT_ID=""
# AZURE_CLIENT_SECRET=""
```

**Run BYO Deployment**

```bash
cp /path/to/key.json ./key.json
./deploy.sh --byo
```

**Verify**

```bash
curl -k https://<CODEMIE_HOST>/v1/healthcheck
```

Expected response: `{"status":"ok"}`
