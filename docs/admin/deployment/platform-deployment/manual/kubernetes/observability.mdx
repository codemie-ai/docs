The steps below are identical across cloud providers except for the Helm values file and the Kibana URL. Substitute `values-<cloud-provider>.yaml` and `<kibana-url>` with the values for your cloud:

| Cloud Provider | Values File         | Kibana URL                     |
| -------------- | ------------------- | ------------------------------ |
| AWS            | `values-aws.yaml`   | `https://kibana.<your-domain>` |
| Azure          | `values-azure.yaml` | `https://<your-domain>/kibana` |
| GCP            | `values-gcp.yaml`   | `https://kibana.<your-domain>` |

AWS and GCP expose Kibana on a dedicated subdomain; Azure exposes it as a path under your main domain.
