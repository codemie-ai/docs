The steps below are identical across cloud providers except for the Helm values file and the Keycloak Admin URL. Substitute `values-<cloud-provider>.yaml` and `<keycloak-admin-url>` with the values for your cloud:

| Cloud Provider | Values File         | Keycloak Admin URL                          |
| -------------- | ------------------- | ------------------------------------------- |
| AWS            | `values-aws.yaml`   | `https://keycloak.<your-domain>/auth/admin` |
| Azure          | `values-azure.yaml` | `https://<your-domain>/keycloak/admin`      |
| GCP            | `values-gcp.yaml`   | `https://keycloak.<your-domain>/auth/admin` |

AWS and GCP expose Keycloak on a dedicated subdomain; Azure exposes it as a path under your main domain.
