Elasticsearch installation is identical across cloud providers except for the Helm values file. Substitute `values-<cloud-provider>.yaml` with `values-aws.yaml`, `values-azure.yaml`, or `values-gcp.yaml` for your cloud.

## PostgreSQL Configuration

PostgreSQL setup differs on AWS, which uses IAM database authentication instead of a static password. Azure and GCP both connect with a static password and only differ in their managed service name and host.

Substitute `<postgres-host>` with your managed PostgreSQL service's connection host:

| Cloud Provider | Managed Service               | Example Host                                   |
| -------------- | ----------------------------- | ---------------------------------------------- |
| Azure          | Azure Database for PostgreSQL | `codemie-postgres.postgres.database.azure.com` |
| GCP            | GCP Cloud SQL PostgreSQL      | `10.0.0.5:5432` (private IP)                   |
