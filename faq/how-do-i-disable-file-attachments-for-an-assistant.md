# How do I disable file attachments for an assistant?

Open the assistant's configuration by clicking the **Actions** button (⋮) next to the assistant and selecting **Edit**. Scroll to the **File attachments** section and toggle off **Enable file attachments**, then click **Save**.

Once disabled, the paperclip icon no longer appears in the chat input toolbar for that assistant, and users cannot upload files during conversations with it.
