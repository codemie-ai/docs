# How do I assign categories to a workflow and filter workflows by category?

Categories are optional and can be set when a workflow is created or edited. In the workflow configuration, open the **Categories** dropdown (below **Icon URL**) and select up to 3 categories. The same list of categories is used for assistants.

To filter, open **My Workflows** or **All Workflows** and select one or more categories in the **Categories** filter in the left sidebar. Only workflows with a selected category are shown; workflows without categories are hidden until the filter is cleared.
