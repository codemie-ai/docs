# What is the Assistant Creator skill? Can it modify or publish my assistants?

Assistant Creator is a public marketplace skill, built into the platform, that creates
assistants through a guided conversation. Instead of filling in the assistant configuration
form, a plain-language description is enough — the skill asks any missing questions, proposes
a complete configuration, and creates the assistant only after explicit confirmation.

It acts only as the requesting user, using only that user's own permissions and only
resources (projects, models, tools, data sources) the user is already permitted to use.

**Assistant Creator cannot:**

- Modify or delete an existing assistant.
- Publish an assistant to the marketplace.
- Create a remote or Bedrock-hosted assistant.
- Bypass the platform's normal validation for assistant creation.
