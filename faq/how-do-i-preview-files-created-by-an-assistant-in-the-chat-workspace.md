# How do I preview files created by an assistant in the chat workspace?

Open the chat and click **Browse files** in the chat header. The **Agent workspace** dialog lists the files of the chat. Selecting a file shows its preview: Markdown is rendered as a formatted document, JSON is pretty-printed, and logs, diffs, configuration files, and source code are shown with syntax highlighting. Images are shown as images.

Click **Expand** to read a long file in a larger popup. Pressing `Esc` closes only the expanded popup, and the dialog stays open with the same file selected. The **Download** button downloads the original file.
