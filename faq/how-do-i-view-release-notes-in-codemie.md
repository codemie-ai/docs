# How do I view Release Notes in CodeMie?

The Release Notes page is accessible from the Help Center. Click the **Help** icon (question mark) in the bottom-left sidebar, then in the **Product Updates** section click **See What's New**.

The page shows all platform versions deployed in the current environment, listed newest first. Each entry includes:

- The version number and deployment date
- **Highlights** — new features and major improvements
- **Fixes** — resolved issues and stability improvements

The most recent version is marked with a **LATEST** badge.
