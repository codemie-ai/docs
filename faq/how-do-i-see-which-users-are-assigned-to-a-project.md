# How do I see which users are assigned to a project?

Go to **Settings → Administration → Projects Management** and click the **Users** badge on the
project's row. This opens Users Management with the **Project** filter already set to that
project, so only its members are listed.

The badge is clickable for Platform Admins, Maintainers, and Auditors. Other users see the member
count without a link.
