# Can I use Get Repository File Tree and Get Repo Tree with filtering (Experimental) together?

In the assistant form, a tool and its "with filtering" variant are mutually exclusive. Selecting **Get Repo Tree with filtering (Experimental)** deselects **Get Repository File Tree**, and the other way around. The same applies to **Search Code Repo** and **Search Code with filtering (Experimental)**. Both tools of a pair can also be deselected.
