# Why does the assistant show a local file path instead of a download link?

The MCP server wrote the file on its own disk but did not deliver it. A local path such as `filesystem:/home/...` cannot be opened from the browser.

To get a Download chip, the server must return the file content (for example, the Filesystem server `read_media_file`), or a stdio server must be opted in with `CODEMIE_EXPORT_FILES=true` and the model must list the file in `codemie_export_files`. When a file still cannot be delivered, the reply says that it stays on the MCP server.

Files from workflow MCP tool nodes and from MCP tools run through CodeMie Plugins are not delivered yet.
