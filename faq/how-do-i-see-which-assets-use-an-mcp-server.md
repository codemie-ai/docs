# How do I see which Assistants, Skills, and Workflows use an MCP server?

Open **Settings** → **Administration** → **MCPs management** (Enterprise package). The **Assignments** column shows three badges per MCP server: the number of Assistants, Skills, and Workflows that reference it. Only assets visible to the current user are counted, and only enabled MCP references.

Click a badge to open the matching asset list filtered to that MCP server. Clear the filter to return to the default list.
