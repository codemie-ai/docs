# Which file types can be previewed in the agent workspace browser?

Markdown (`.md`, `.markdown`), JSON, common images, and any text or source file with an extension supported by chat code blocks, including `.log`, `.diff`, `.txt`, `.yaml`, `.sh`, `.html`, as well as `Dockerfile`, `Makefile`, and dotfiles such as `.env`. HTML is shown as text and is never executed in the application. PDF, Office documents, and other binary files show a "no preview" hint and can only be downloaded.
