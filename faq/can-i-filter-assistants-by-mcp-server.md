# Can I filter assistants by MCP server?

Yes. The **Project Assistants** list has an **MCP servers** filter when the MCP feature is enabled. It is a searchable multi-select; an assistant is shown when it has any of the selected servers attached and enabled. The filter is also pre-selected when the Assistants count is clicked on the **MCPs management** page.

If the selected MCP server was deleted or is not accessible, an empty state is displayed instead of the unfiltered list.
