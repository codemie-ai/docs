# How do I get notified when an AI response is ready while the CodeMie tab is inactive?

When a response completes while the CodeMie tab is in the background, the tab title is prefixed with `Response ready -`. If browser notifications are allowed for the CodeMie site, a **CodeMie** notification with the text **AI response is ready** is also shown. Returning to the tab clears the indicator.

To enable notifications:

1. Submit a prompt in a chat.
2. When the browser asks about notifications from the CodeMie site, select **Allow**.
3. If no prompt appears, allow **Notifications** for the site in the browser settings (lock icon in the address bar).

Without notification permission, the tab title indicator still works. Nothing is shown when the CodeMie tab is active, or when the response fails or is stopped.
