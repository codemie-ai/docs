# System instructions? Instructions history? System instructions version rollback? System instructions version management?

When working with assistants, different system instructions can produce different outcomes. The latest instructions do not always produce the best results, so reverting to earlier versions may be necessary. AI/Run CodeMie tracks all saved changes to system instructions automatically.

To browse or restore a previous version of system instructions:

1. Open the assistant for editing (**Assistants** → **Project Assistants** → **Actions** (⋮) → **Edit**).
2. In the **System Instructions** section, click **Version History**.
3. Select a version from the dropdown and review the side-by-side diff.
4. Click **Restore** and confirm the action.
5. Click **Save** on the Edit Assistant page to persist the restored instructions.
