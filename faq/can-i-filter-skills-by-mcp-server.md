# Can I filter skills by MCP server?

Yes. The **Project Skills** list has an **MCP Servers** filter available to all users. It is a searchable multi-select; a skill is shown when it references any of the selected servers. The filter is also pre-selected when the Skills count is clicked on the **MCPs management** page.

If the selected MCP server was deleted or is not accessible, an empty state is displayed instead of the unfiltered list.
