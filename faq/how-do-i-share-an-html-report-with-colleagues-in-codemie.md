# How do I share an HTML report with colleagues in CodeMie?

Upload the report as a hosted application. Open **Applications**, select **Create application**, choose a project, enter a name and a description, and add the `.html` file (up to 20 MiB) or a ZIP of a prebuilt static site (up to 100 MiB). CodeMie validates the upload and scans it for malware. When the version is **Ready**, select **Activate version** and confirm.

New applications are private. To give access, open the application and select **Share**: add colleagues by name, or select **Copy share link** and send the link. Signed-in colleagues open the report inside CodeMie and cannot edit it. **Revoke link** removes access through the link. To share with a whole project, turn on **Shared with project**.

The hosted applications feature must be turned on by the CodeMie administrator.
