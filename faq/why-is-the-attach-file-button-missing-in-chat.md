# Why is the attach file button missing in chat?

The paperclip icon in the chat input toolbar is only shown when the assistant's creator has enabled file attachments in the assistant configuration. If the icon is not visible, file uploads have been disabled for that assistant.

To enable file attachments, the assistant's creator or maintainer must open the assistant's **Edit** page, navigate to the **File attachments** section, and toggle on **Enable file attachments**.
