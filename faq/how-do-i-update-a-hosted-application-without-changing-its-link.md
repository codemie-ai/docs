# How do I update a hosted application without changing its link?

Upload a new version of the same application. Open the application details and select **Upload version**, or select **Upload new version** in the card menu (**⋮**). CodeMie checks the new version for security. When it is **Ready**, select **Activate version** and confirm.

The link stays the same. People with access keep seeing the previous version until the new one is activated. To roll back, activate an earlier **Ready** version.
