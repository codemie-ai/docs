# How do I check if a scheduler integration is enabled or disabled?

The enabled/disabled state of each scheduler integration is shown directly in the Integrations list — no need to open individual records.

1. Go to **Integrations** in the main menu.
2. Select **Project** or **User** tab depending on where the scheduler was created.
3. Find the scheduler entry in the list — its enabled or disabled state is shown as a visible indicator next to the record.

To change the state, open the record and toggle the **Is Enabled** field.
