# How do I add an application to the CodeMie Applications tab?

The corporate operations team registers each application as a tile in the CodeMie configuration and restarts CodeMie to apply it. There is no self-service screen. The application team provides a tile entry with the name, description, icon, URL, and tile type (`link`, `iframe`, or `module`).

Before registration, choose where the application runs. Running it on the team's own infrastructure is preferred, either on its own domain or behind a CodeMie route. Hosting inside CodeMie's cluster is agreed case by case. Embedded and hosted applications also pass a security review before go-live.

A static page, such as an HTML report, a slide deck, or a prebuilt static web build, needs no registration. When the hosted applications feature is on, any signed-in user can upload it from **Applications** > **Create application** and share it.
