# Can I use Get Repo Tree and Get Repo Tree with filtering together?

In the assistant form, a tool and its "with filtering" variant are mutually exclusive. Selecting **Get Repo Tree with filtering** deselects **Get Repo Tree**, and the other way around. The same applies to **Search Code** and **Search Code with filtering**. Both tools of a pair can also be deselected.
