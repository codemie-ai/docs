# How do I reset a project member to the project default models?

Open **Settings → Administration → Projects management**, select the project, and switch to the
**Members** tab. Click the **⋮ (Actions)** menu on the member's row, select **Override models**,
click **Reset to project settings**, confirm the prompt, and click **Apply changes**.

The member's override is removed, so the member uses the project's model configuration and default
model again, and the sparkle icon disappears from the member's row.

**Reset to project settings** is disabled for members who have no custom model settings. To find
members that have an override, set the **Model Settings** filter on the **Members** tab to
**Custom**.
