# How are Headroom token savings shown?

In a chat, the **Usage details** overlay in the chat header shows a **Tokens saved (Headroom)** row with the number of saved tokens and the percentage of the original token count. The row appears only when compression saved tokens.

Aggregated figures are available in the **Context Compression** section of the **Insights** tab on the Analytics page, which shows a summary, savings over time, and savings by strategy. The section is shown only when the `features:headroom` customer feature is enabled.
