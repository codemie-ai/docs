# How do I see who created a budget in CodeMie?

Open **Profile → Settings → Administration → Budgets**. The budget list has a **Created By** column with the name of the user who created each budget. To see all properties of a budget, open the actions menu of its row and select **View details**.

Preconfigured budgets defined in platform configuration show **System**. If the creator is no longer available, for example a deleted user, the value shows **—**. The creator is recorded when the budget is created and does not change when the budget is edited.

The budget list and details are available to users with the Maintainer, Admin, or Auditor role.
